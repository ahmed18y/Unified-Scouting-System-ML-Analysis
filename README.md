# FIFA Player Scouting ML

A machine learning project focused on FIFA player analysis, scouting, and performance evaluation using Python.

## Features
- Exploratory Data Analysis (EDA)
- Data preprocessing
- Feature engineering
- Player performance analysis
- Machine Learning models
- Data visualization

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset
The project uses FIFA player data for analysis and prediction tasks.
